# Contributing

This repository holds the released Signlytic AI apps and their user
documentation. The source code lives in
[Signlytic_AI](https://github.com/Iyanuoluwa007/Signlytic_AI), and so do the
contribution rules: read its
[CONTRIBUTING.md](https://github.com/Iyanuoluwa007/Signlytic_AI/blob/main/CONTRIBUTING.md)
before you start.

In short:

- Issues filed here usually need code changes. Open the pull request in
  Signlytic_AI and write `Fixes Iyanuoluwa007/Signlytic-Overlay#<number>` in it.
  Pull requests here are for this repository's documentation only.
- Nothing merges without the maintainer's approving review. The pull request
  template's human verification checklist must be complete first, including
  whether you used AI tools and confirmation that you checked their output.
- Never commit sign pose data, dataset media, avatar models or secrets.
